# homebrew-calwidget

Homebrew tap for [CalWidget](https://github.com/Hitjack007/CalWidget), a macOS widget that shows your Google Calendar as a month view.

## Install

```bash
brew install --cask hitjack007/calwidget/calwidget
```

Or add the tap first:

```bash
brew tap hitjack007/calwidget
brew install --cask calwidget
```

## Update

CalWidget updates itself. To update through Homebrew instead:

```bash
brew upgrade --cask calwidget
```

The cask in `Casks/` is updated automatically by CalWidget's release script, so don't edit it by hand.
